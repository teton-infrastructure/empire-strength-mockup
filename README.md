- **Live preview:** https://empire-strength-mockup.pages.dev
- **Site source:** [`site/`](site/). Static HTML/CSS with a tiny bit of vanilla JS (mobile menu). No build step.
- **Screenshots:** `old-site-desktop.png`, `old-site-mobile.png`, `mockup-desktop.png`, `mockup-mobile.png` (first screen), `mockup-mobile-full.png`
- **Audit:** [`score.md`](score.md) · **Pitch:** [`pitch.md`](pitch.md)
- Logo, award badges and facility photos © Empire Strength and Fitness, reused from empirestrengthandfitness.com for this pitch. No people, reviews or stats were invented.
- The page carries `noindex` (meta + `X-Robots-Tag`) so it won't compete with the real site.
